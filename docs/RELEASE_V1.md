# Version 1 — точка отката перед БС-балансером

Версия сохраняет весь текущий код и документацию до добавления функции
приоритетной балансировки A → B.

- `ios-fix-beta` переименован в `ios-fix-dns` в коде, CLI и документации.
- Старые имена режима в `.env` и SQLite принимаются как алиасы `ios-fix-dns`.
- Сохранены текущие исправления TLS verifyPeerCertByName и связанные тесты.
- Включены аудит iPhone, проект A → B и имеющийся план EDGE/CDN.
- Полный набор тестов этой версии: 59 passed.

Тег `v1` должен оставаться на исходном коммите и не перемещаться при дальнейших
обновлениях. В GitHub Release автоматически доступны архивы исходников этого коммита.

## Откат

На сервере с чистым рабочим деревом:

```bash
git fetch origin --tags
git switch --detach v1
python -m app.cli service restart
```

Локальные `.env`, SQLite и виртуальное окружение не входят в релиз и сохраняются.
Если Git сообщает о незакоммиченных изменениях, сначала сохраните их; не используйте
принудительный reset для обхода этой проверки. Для возврата к обновлениям:

```bash
git switch main
git pull --ff-only origin main
python -m app.cli service restart
```
