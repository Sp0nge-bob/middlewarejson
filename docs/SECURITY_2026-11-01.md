# CaelixFlow Subscription Middleware — security candidate 2026-11-01

**Для push/review. Не production-ready; не опубликован и не развёрнут.**
Ветка: `security-fixes/2026-11-01`. Исходный commit: `2f089e0ba14a2057dfc97c8996860b90b89c1d95`.

## Изменения

- Удалены bearer sub_id, URL, фрагменты конфигураций и сырые исключения из выбранных application/HTTPX/httpcore/Uvicorn logs; добавлена HMAC-корреляция.
- BOM-prefixed JSON разбирается после той же нормализации, что и проверка формата.
- Потоковый приём ограничивает декодированное тело по MAX_UPSTREAM_BODY_BYTES:2097152 байт по умолчанию. Wire budget = этот предел+65536; gzip/deflate выход ограничен до сохранения данных.
- REQUEST_TIMEOUT_SEC также ограничивает полное I/O. Превышение бюджета, повреждённое или неподдерживаемое сжатие дают502.
- В ios-fix-dns частные исключения сохраняют порядок, catch-all ставится до общего fallback, используются существующие proxy/balancer targets. Allowlist-граф не переписывается.

## Совместимость

VPN credentials, настройки реальных серверов и зависимости не менялись.

конкурентная привязка бота/сайта проверены на фиктивной общей SQLite.
